# 物品信息数据约定

所有物品保存在同一个数组中。每条记录包含：

| 字段        | 含义                                       |
| ----------- | ------------------------------------------ |
| id          | 每条信息的唯一编号                         |
| type        | `lost` 表示寻物，`found` 表示招领          |
| name        | 物品名称，搜索时使用                       |
| category    | 物品类别                                   |
| description | 外观特征等描述                             |
| location    | 丢失或拾取地点                             |
| eventTime   | 丢失或拾取时间                             |
| contact     | 发布者提供的联系方式                       |
| status      | `active` 表示处理中，`resolved` 表示已完成 |
| ownerId     | 发布者在当前浏览器中的标识                 |
| createdAt   | 发布时间                                   |

状态显示规则：寻物的 `resolved` 显示“已找到”；招领的 `resolved` 显示“已归还”。

发布页的名称、分类、时间、地点、外观特征、联系方式均为必填项，提交时去除首尾空白。`eventTime` 支持原型中的文字时间（如“9月26日 下午三点”），也兼容已有演示数据的 ISO 时间；`createdAt` 由程序生成 ISO 时间。

发布记录保存在当前浏览器的 `localStorage.shiguang_items_v1`，发布者标识保存在 `localStorage.shiguang_owner_v1`。新记录初始状态为 `active`。保存成功后更新首页和搜索列表，“我的发布”按发布者标识筛选；保存失败时保留表单内容并提示重试。当前数据不在不同浏览器或设备间共享，清除浏览器数据会删除本地发布记录。
